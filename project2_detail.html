"LogiPO-Bot" PO Automation

An end-to-end workflow utilizing OCR, LINE Messaging API, and Google Apps Script to streamline Purchase Order approvals and ERP synchronization. ระบบจัดการและอนุมัติใบสั่งซื้อ (PO) อัตโนมัติแบบครบวงจร ด้วยเทคโนโลยี OCR, LINE Messaging API และ Google Apps Script เชื่อมต่อตรงเข้าสู่ระบบ ERP

1. Gap Analysis & Business Case 1. การวิเคราะห์ปัญหาและผลลัพธ์ทางธุรกิจ (Gap Analysis & Business Case)

As-Is (Current State) As-Is (กระบวนการทำงานแบบเดิม)

  • Off-System Processing: Manual PO creation outside the ERP causes severe operational bottlenecks.
  • Delayed Cash Flow Visibility: Accounting struggles to accurately update weekly cash flow reports due to significant data lag.
  • Inefficient Approvals: Physical document routing delays decisions and creates blind spots in tracking.
  • Data Integrity Risks: High risk of duplicate data entry when eventually syncing into the ERP.
  • การทำเอกสารนอกระบบ (Off-System Processing): การเปิดใบสั่งซื้อ (PO) แบบ Manual นอกระบบ ERP ทำให้เกิดคอขวดในการทำงานหน้างาน
  • ข้อมูลกระแสเงินสดล่าช้า (Delayed Cash Flow Visibility): ฝ่ายบัญชีไม่สามารถอัปเดตรายงานกระแสเงินสดรายสัปดาห์ได้อย่างแม่นยำเนื่องจากข้อมูล PO เข้าระบบล่าช้า
  • การรออนุมัติที่ไร้ประสิทธิภาพ (Inefficient Approvals): การเดินเอกสารกระดาษทำให้การตัดสินใจล่าช้าและติดตามสถานะเอกสารได้ยาก
  • ความเสี่ยงข้อมูลซ้ำซ้อน (Data Integrity Risks): เสี่ยงต่อการคีย์ข้อมูลซ้ำซ้อนหรือผิดพลาดเมื่อต้องนำมาบันทึกลงระบบ ERP ย้อนหลัง

To-Be (Target State) To-Be (กระบวนการทำงานอัตโนมัติ)

  • Automated Data Capture: Smart PO extraction via LINE OCR transforms off-system documents into digital data instantly.
  • Real-Time Cash Flow Visibility: Instant API injection into the ERP enables Accounting to generate accurate, up-to-date weekly cash flow reports without delay.
  • Seamless Approval Workflow: 100% paperless and dynamic Email approvals ensure fast decision-making and eliminate tracking blind spots.
  • Systematic Data Governance: Built-in duplicate checks and validation rules secure data integrity before ERP integration.
  • สกัดข้อมูลอัตโนมัติ (Automated Data Capture): อ่านข้อมูลจากไฟล์ PDF ใบสั่งซื้อผ่าน LINE OCR แปลงเป็นข้อมูลดิจิทัลพร้อมตรวจสอบทันที
  • เห็นภาพรวมกระแสเงินสดแบบ Real-Time: ส่งข้อมูลเข้า ERP ผ่าน API ทันทีที่อนุมัติ ช่วยให้ฝ่ายบัญชีจัดทำรายงานกระแสเงินสดรายสัปดาห์ได้ถูกต้องและรวดเร็ว
  • อนุมัติไร้กระดาษ 100% (Seamless Approval Workflow): ส่งอีเมลขออนุมัติแบบโต้ตอบอัตโนมัติ ช่วยให้ผู้บริหารตัดสินใจได้รวดเร็วและตรวจสอบสถานะได้ทุกขั้นตอน
  • ควบคุมคุณภาพข้อมูล (Systematic Data Governance): มีระบบเช็คเลขที่เอกสารซ้ำ (New / Revision / Locked) ก่อนส่งเข้า ERP ป้องกันการตั้งหนี้ซ้ำซ้อน 100%

2. System Architecture & Data Flow 2. สถาปัตยกรรมระบบและลำดับการไหลของข้อมูล (System Architecture & Data Flow)

The system is designed with a strong focus on data governance, utilizing Google Sheets as a staging database for duplicate validation and formatting prior to REST API execution into TRCloud ERP.

ออกแบบโดยเน้นการควบคุมความถูกต้องของข้อมูล (Data Governance) โดยใช้ Google Sheets เป็นพื้นที่พักข้อมูล (Staging Area) เพื่อตรวจสอบสถานะเอกสารซ้ำและจัดรูปแบบข้อมูลให้ตรงตามมาตรฐาน API ก่อนยิงเข้าสู่ระบบ TRCloud ERP

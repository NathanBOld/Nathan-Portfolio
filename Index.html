Hero Project

"LogiPO-Bot" PO Automation

Challengeปัญหา

Manual PO data entry and physical approval bottlenecks delayed weekly cash flow visibility.

การคีย์ใบสั่งซื้อ (PO) ด้วยมือและการเดินเอกสารขออนุมัติที่ล่าช้า ทำให้ไม่สามารถอัปเดตงบกระแสเงินสดรายสัปดาห์ได้ทันเวลา

Solutionโซลูชัน

End-to-end workflow using OCR, LINE Messaging API, and Google Apps Script to extract PO data, enforce duplicate checks, route email approvals, and sync directly into the ERP.

Workflow อัตโนมัติด้วย OCR, LINE Messaging API และ Google Apps Script เพื่อสกัดข้อมูล PO ตรวจสอบเอกสารซ้ำ ส่งอีเมลขออนุมัติแบบโต้ตอบ และส่งข้อมูลเข้า ERP ทันที

OCR LINE API Google Apps Script

Hero Project

Automated AR Reconciliation & Multi-Invoice Payment Splitting

Challengeปัญหา

Manual Copy/Paste file generation took over 2 hours daily, and legacy VLOOKUP reconciliation was error-prone and hard to audit.

การทำไฟล์ตัดรับชำระแบบ Manual ใช้เวลามากกว่า 2 ชั่วโมงต่อวัน และสูตร VLOOKUP เดิมเสี่ยงต่อความผิดพลาดและตรวจสอบยาก

Solutionโซลูชัน

Power Query ETL model for 3-way matching (3PL, TMS, ERP) plus VBA macros that split TMS upload files and output a ready-to-paste dataset (3PL Code, InvoiceNumber, Amount) for the Bulk RV API Web App.

โมเดล Power Query ETL ทำ 3-Way Matching (3PL, TMS, ERP) คู่กับ VBA เพื่อแยกไฟล์อัปโหลดเข้า TMS และสร้างชุดข้อมูลสำเร็จรูป (ตัวย่อ 3PL, InvoiceNumber, ยอดเงิน) พร้อมส่งต่อเข้า Bulk RV API Web App

Power Query ETL Excel VBA 3-Way Matching

Hero Project

Bulk RV API Web App (3PL COD Settlement)

Challengeปัญหา

Over 10,000 COD transactions per month, with single 3PL payouts covering thousands of invoices. Native ERP filters couldn't query by 3PL settlement parameters, which forced line-by-line clearing.

รายการ COD กว่า 10,000 บิล/เดือน ที่ขนส่งโอนรวมเป็นก้อน แต่ ERP เดิมไม่สามารถกรองบิลตามพารามิเตอร์ของ 3PL ได้ ทำให้ต้องคีย์ตัดรับชำระทีละใบ

Solutionโซลูชัน

Middleware Web App (HTML/JS & Apps Script) that ingests the reconciled dataset from the 3-Way Reconciliation tool and batch-posts Receipt Vouchers via REST API in under 2 seconds.

Middleware Web App (HTML/JS และ Apps Script) รับชุดข้อมูลที่ผ่านการ Reconcile จาก 3-Way Reconciliation แล้วสร้างใบสำคัญรับ (RV) แบบกลุ่มผ่าน REST API เสร็จภายใน 2 วินาที

REST API (JSON / MD5) JS / HTML Web App Batch AR Settlement

System Architecture

TMS–ERP Integration Architecture

Challengeปัญหา

The Epicor → TRCloud migration had to eliminate redundant Sales Orders and manual invoicing, and handle multi-channel revenue and Tax Point recognition (Bank Transfer, 2c2p, COD).

การย้ายระบบจาก Epicor สู่ TRCloud ต้องขจัด Sales Order ซ้ำซ้อนและการเปิด Invoice ด้วยมือ รวมถึงจัดการ Tax Point และการรับรู้รายได้แยกตามช่องทางชำระเงิน (Bank Transfer, 2c2p, COD)

Solutionโซลูชัน

Field-level mapping specs covering 12 scenarios across 5 API endpoints (IV, MR, CN, Update IV, GL), with automated Tax Point anchoring, 3PL AR mapping, and midnight GL cut-off/reversal.

System Mapping Spec ระดับ Field-level ครอบคลุม 12 เงื่อนไขธุรกิจ บน 5 API Endpoints (IV, MR, CN, Update IV, GL) พร้อมสูตรบัญชีอัตโนมัติ ตั้งหนี้ลูกหนี้ขนส่ง และ GL Cut-off/Reversal ตอนเที่ยงคืน

12 Scenarios / 5 Endpoints API Payload Mapping Automated GL & Tax Point

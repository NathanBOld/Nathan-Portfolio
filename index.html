Hero Project

"LogiPO-Bot" PO Automation

Challenge: Slow, manual PO data entry and physical executive approval bottlenecks delayed weekly cash flow visibility.

Solution: Engineered an end-to-end workflow using OCR, LINE Messaging API, and Google Apps Script to extract PO data, enforce duplicate checks, route dynamic email approvals, and sync directly into the ERP.

ปัญหา: การคีย์ข้อมูลใบสั่งซื้อ (PO) ด้วยมือและการเดินเอกสารขออนุมัติที่ล่าช้า ทำให้ฝ่ายบัญชีไม่สามารถอัปเดตงบกระแสเงินสดรายสัปดาห์ได้ทันเวลา

โซลูชัน: พัฒนา Workflow อัตโนมัติด้วย OCR, LINE Messaging API และ Google Apps Script เพื่อสกัดข้อมูล PO ตรวจสอบเอกสารซ้ำ ส่งอีเมลขออนุมัติแบบโต้ตอบ และยิงข้อมูลเข้าสู่ ERP ทันที

Hero Project

Automated AR Reconciliation & Multi-Invoice Payment Splitting

Challenge: Manual file generation (Copy/Paste) took >2 hours daily, while legacy VLOOKUP reconciliation was prone to formula errors and difficult to audit.

Solution: Built a Power Query ETL model for automated 3-way matching across 3PL, TMS, and ERP—paired with VBA macros to split TMS upload files and generate a pre-formatted dataset (3PL Code, InvoiceNumber, Amount) ready for direct Copy & Paste into the Bulk RV API Web App.

ปัญหา: การทำไฟล์ตัดรับชำระเงินแบบ Manual (Copy/Paste) ใช้เวลามากกว่า 2 ชั่วโมงต่อวัน และการผูกสูตร VLOOKUP เดิมเสี่ยงต่อความผิดพลาดและตรวจสอบยาก

โซลูชัน: สร้างโมเดล Power Query ETL ทำ 3-Way Matching (3PL, TMS, ERP) คู่กับ VBA เพื่อแยกไฟล์อัปโหลดเข้า TMS และสร้างชุดข้อมูลสำเร็จรูป (ตัวย่อ 3PL, InvoiceNumber, ยอดเงินแต่ละบิล) ที่พร้อมส่งต่อเข้าสู่ Bulk RV API Web App

Hero Project

Bulk RV API Web App (3PL COD Settlement)

Challenge: High-volume COD transactions (>10k/month) where a single 3PL payout covers thousands of invoices. Native ERP filters could not query or cross-reference invoices using external 3PL settlement parameters, forcing manual line-by-line clearing.

Solution: Developed a middleware Web App (HTML/JS & Google Apps Script) that seamlessly ingests the reconciled dataset (3PL Code, InvoiceNumber, Amount) from the 3-Way Reconciliation tool via Copy & Paste and batch-posts Receipt Vouchers (RV) via REST API in under 2 seconds.

ปัญหา: รายการเก็บเงินปลายทาง (COD) กว่า 10,000 บิล/เดือน ที่ขนส่งโอนเงินรวมมาเป็นก้อน แต่ระบบ ERP เดิมไม่สามารถกรองหรืออ้างอิงบิลตามพารามิเตอร์จากรายงานของขนส่ง (3PL) ได้ ทำให้ต้องคีย์ตัดรับชำระทีละใบ

โซลูชัน: พัฒนา Middleware Web App (HTML/JS และ Google Apps Script) ที่รับชุดข้อมูลซึ่งผ่านการ Reconcile แล้ว (ตัวย่อ 3PL, InvoiceNumber, ยอดเงิน) ต่อเนื่องจากโปรเจกต์ 3-Way Reconciliation ผ่านการ Copy & Paste เพื่อยิงสร้างใบสำคัญรับ (RV) แบบกลุ่มผ่าน REST API เสร็จภายใน 2 วินาที

System Architecture

TMS-ERP Integration Architecture

Challenge: Migrating from Epicor to TRCloud ERP required eliminating redundant Sales Order creation, manual invoicing, and complex multi-channel revenue & Tax Point recognition (Bank Transfer, 2c2p, COD).

Solution: Authored field-level System Mapping Specifications across 12 business scenarios on 5 API endpoints (IV, MR, CN, Update IV, GL) with automated Tax Point anchoring, 3PL Carrier AR mapping, and simultaneous midnight GL Cut-off/Reversal logic.

ปัญหา: การย้ายระบบจาก Epicor สู่ TRCloud ERP ต้องขจัดการสร้าง Sales Order ซ้ำซ้อน ลดการเปิด Invoice ด้วยมือ และจัดการความซับซ้อนของจุดความรับผิดทางภาษี (Tax Point) และการรับรู้รายได้แยกตามช่องทางชำระเงิน (Bank Transfer, 2c2p, COD)

โซลูชัน: ออกแบบโครงสร้างและเขียน System Mapping Specification ระดับ Field-level ครอบคลุม 12 เงื่อนไขธุรกิจ บน 5 API Endpoints (IV, MR, CN, Update IV, GL) พร้อมผูกสูตรบัญชีอัตโนมัติ ตั้งหนี้ลูกหนี้ขนส่ง และยิงปรับปรุง/กลับรายการรายได้และต้นทุนสินค้าระหว่างทาง (GL Cut-off/Reversal) ตอนเที่ยงคืน

ERP & Executive BI

Epicor ERP Analytics & Dashboard Development (~30 Modules)

Challenge: Fragmented relational ERP tables left Accounting, Procurement, Logistics, and Warehouse teams relying on manual Excel VLOOKUPs while executives lacked real-time financial visibility.

Solution: Authored ~30 System Specifications (featuring 7 flagship modules: ICRID001–005, 007–008), deployed native BAQ operational dashboards, and exposed JSON REST API pipelines to power interactive Power BI Executive Financial Dashboards (GP, Cost, Cash Flow).

ปัญหา: โครงสร้างตารางฐานข้อมูล ERP ที่กระจายตัวทำให้ทีมบัญชี จัดซื้อ โลจิสติกส์ และคลังสินค้าต้องดึง Excel มาผูกสูตร VLOOKUP เอง และผู้บริหารไม่เห็นภาพรวมทางการเงินแบบ Real-time

โซลูชัน: ออกแบบ System Specification และพัฒนา BAQ สร้างแดชบอร์ดภายในระบบ Epicor เกือบ 30 โมดูล (แสดงตัวอย่างเด่น 7 โมดูล: ICRID001–005, 007–008) พร้อมเปิด REST API (JSON) ดึงเข้าสู่ Power BI สร้าง Executive Financial Dashboard วิเคราะห์กำไรขั้นต้น (GP), โครงสร้างต้นทุน และกระแสเงินสด
